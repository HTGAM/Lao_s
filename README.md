# 🥇 다국어 교통 안전 AI 안내 앱 (Multilingual Traffic Safety AI Guide)

이 프로젝트는 고등학생 3명과 Antigravity AI Agent가 함께 협업하며, AI 핵심 프롬프트 설계(Vibe Coding)를 통해 설계 및 구현된 외국인 관광객 맞춤형 교통 안전 안내 웹 어플리케이션입니다.

---

## 🔧 주요 기능
1. **실시간 카메라 스캔 및 이미지 업로드**: 
   - 브라우저의 카메라 API 및 이미지 선택 기능 지원.
2. **AI OCR 판독 (Tesseract.js)**:
   - 서버 없이 브라우저 내에서 직접 이미지 내 한글 텍스트 판독.
3. **AI 프롬프트 엔지니어링 콘솔**:
   - 시스템 프롬프트(지시문) 수정에 따라 번역 스타일, 안전 조치 사항 및 경고문의 톤이 실시간으로 다이내믹하게 컴파일되는 프롬프트 시뮬레이션 탑재.
4. **다국어 음성 안내 (Web Speech API)**:
   - 영어(US), 라오어(Lao), 중국어(Mandarin), 일본어(JP) 네이티브 발음 및 말하기 속도 자동 튜닝 제공. 라오스 관광객을 위한 다국어 안전 가이드 구현.
5. **하드웨어 경고음 경보 (Web Audio API)**:
   - 교통 표지판의 위험도(High, Medium, Low)에 맞춘 다차원 오실레이터 사이렌 경보 작동.
6. **실시간 자동 인식 루프 (Auto Scan)**:
   - 촬영 버튼을 따로 누르지 않고 카메라만 비추고 있어도, 3초 간격으로 자동 스캔하여 실시간 분석 및 다국어 번역을 자동으로 반영하는 스마트 스캐너 모드 지원.

---

## 🚀 실행 방법
이 프로젝트는 순수 **HTML/JS/CSS**로 구축되어 별도의 복잡한 서버 설치 없이 즉시 실행 가능합니다.

1. **단순 실행**:
   - `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 등 최신 웹 브라우저에서 직접 더블 클릭하여 엽니다.
2. **로컬 서버 실행 (카메라 권한 및 OCR 라이브러리 차단 해제 권장)**:
   - 브라우저의 보안 정책상 카메라 작동은 `localhost`나 `https` 보안 환경에서만 원활히 이루어집니다. 아래 명령어를 터미널에서 실행하여 테스트하실 수 있습니다:
     ```bash
     # Python 3 이용 시
     python -m http.server 8000
     
     # Node.js가 설치되어 있을 시
     npx serve .
     ```
   - 실행 후 브라우저에서 `http://localhost:8000` 또는 주어지는 주소로 접속하면 완벽히 작동합니다.

## 👥 고등학생 팀원 발표 스토리텔링 & 역할 매핑
본 데모는 심사위원 앞에서 세 명의 팀원이 함께 발표하기에 최적의 시나리오를 제공합니다.

- **팀원 A (AI 프롬프트 엔지니어)**
  - 역할: AI 시스템 지시어 설계 및 OCR 파이프라인 결합.
  - 발표 연출: 우측 **AI Prompt Engineering Console**에서 프롬프트를 *'🚨 Strict Alert Tone'*으로 변환하여 경고문을 엄격하게 만들거나, *'😊 Warm Tour Guide'*로 변경하여 따뜻하게 설명하는 모습을 실시간으로 시연합니다.
- **팀원 B (UI/UX 및 서비스 기획자)**
  - 역할: 모바일 환경을 모사한 Glassmorphism 기반의 프리미엄 테마 설계, TTS 파동 인터페이스 및 사운드 청각 가이드 설계.
  - 발표 연출: 교통 표지판의 위험 수준에 따른 UI 테두리 색상 변화(빨강/노랑) 및 Web Speech API 기반 음성 성우 기능의 사용성을 설명합니다.
- **팀원 C (테스트 시나리오 및 데이터 분석)**
  - 역할: 실제 도로 위 표지판 이미지 수집 및 카메라 OCR 오차 검증.
  - 발표 연출: 좌측의 **Demo Presets** 버튼들을 눌러 표지판마다 위험 오디오 사이렌이 다르게 울리는 점과, 실제 찍은 표지판 사진을 파일 업로드하여 OCR로 판독해내는 과정을 데모합니다.
